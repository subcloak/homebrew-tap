# Subcloak Homebrew tap

```sh
brew install --cask subcloak/tap/cloak-proxy
```

[Cloak Proxy](https://subcloak.com/apps/cloak-proxy) is a free native macOS HTTPS debugging proxy with an API client and an MCP server, signed with a Developer ID and notarized by Apple. The cask installs the app and links `cloakctl` into your PATH.

Update with `brew upgrade --cask cloak-proxy`. Issues: [subcloak/cloak-proxy](https://github.com/subcloak/cloak-proxy/issues).
